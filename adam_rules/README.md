This folder is for the SQL engine ADaM rule implementations.

To create a new ADaM rule, run `python new-rule.py` and answer `adam` when asked which rules directory to use. To test ADaM rules, run the test script directly with the `-s adam` option (eg `python test.py -s adam -r <rule-id>`) - see Advanced Usage in the [main README](../README.md#advanced-usage).

We intend in the future to categorise the rules more fully, rather than simply having a separate space for ADaM rules, but while there is still significant work being done on SDTM we wanted to avoid changing the structure and workflow.
