This folder is for the ADaM rules. SDTM rules are in the `sdtm_rules` folder.

To create a new ADaM rule, run `python new-rule.py` and answer `adam` when asked which rules directory to use. To test ADaM rules, run the test script directly with the `-s adam` option (eg `python test.py -s adam -r <rule-id>`) - see Advanced Usage in the [main README](../README.md#advanced-usage).
